Retail Sales - Exploratory Data Analysis (EDA)
Project Overview
This project focuses on the Exploratory Data Analysis (EDA) phase of a data science project. I analyzed a retail sales dataset to extract business insights regarding product performance and the impact of marketing strategies (discounts).

Insights & Analysis
Product Performance: Visualized total revenue per product category to identify top-performing assets.

Discount Impact: Analyzed the distribution of sales amounts with and without discounts using Boxplots to identify price sensitivity.

Trend Analysis: Studied sales patterns across different days of the week.

Technologies Used
Python

Pandas for data manipulation.

Seaborn & Matplotlib for advanced data visualization.
